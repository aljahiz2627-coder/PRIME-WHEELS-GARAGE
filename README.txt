PRIME WHEELS GARAGE — Website Company Profile

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder ini di Visual Studio Code.
3. Jalankan index.html dengan ekstensi Live Server.
4. Menu Home, About Us, Katalog, Tokyo Drift dan Hubungi Kami sudah saling terhubung.

Struktur:
- index.html
- about.html
- css/style.css
- js/script.js
- assets/images/logo.png
- assets/images/favicon.png
